# نبيه | Nabeeh Health App

## تشغيل النسخة الجديدة
1. أنشئي بيئة بايثون وثبتي المكتبات: `pip install fastapi uvicorn requests python-dotenv python-multipart email-validator`
2. أضيفي `OPENAI_API_KEY` إلى ملف `.env` في جذر المشروع.
3. شغلي: `python -m uvicorn backend.main:app --reload`
4. افتحي http://127.0.0.1:8000

## تنبيه
- الواجهة الجديدة نموذج تجريبي مستقل داخل نفس المستودع.
- المقالات الظاهرة أمثلة واجهة وليست حقائق طبية تم التحقق منها.
- مسار الشات يستخدم OpenAI مع جدول moh_articles. أبقيت ملفات scraper السابقة كما هي؛ يلزم توحيد إدخال المقالات إلى هذا الجدول قبل الاعتماد عليه.
- لا ترفعي .env أو مفاتيح API أو قواعد بيانات محلية إلى GitHub.
- إعداد إرسال البريد وتخزين الصور الفعلي يحتاج استكمال إعدادات الخدمة قبل الإطلاق.
